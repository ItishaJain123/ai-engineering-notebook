Beyond Text: Images, Audio, and Other Modalities

General AI Eng a map of the wider GenAI landscape — diffusion models, multimodal models, and where Claude fits

Why this matters. "GenAI" is bigger than chatbots. Image generators (Midjourney, DALL-E), voice assistants, and video generators (Sora) are all "generative AI" too — but they work on a different core mechanism than the token-by-token prediction from Chapter 0a. You don't need to build these, but you should recognize the landscape, and understand how Claude's own image/vision abilities (used in Chapter 7, Computer Use) fit in.

1. Text generation vs. image generation — different core idea

Text models (Claude, GPT)Image models (Midjourney, DALL-E, Stable Diffusion)
Core mechanismPredict the next token, one at a timeStart from random noise and gradually remove noise until an image emerges
Architecture familyTransformerDiffusion model (often paired with a transformer for understanding the text prompt)
OutputSequential — one token after anotherThe whole image refines together, all at once, over many steps

2. How diffusion models work (the "sculpture" analogy)

Analogy: imagine a sculptor who was trained by watching millions of statues slowly get eroded into a pile of rubble, in reverse slow-motion — and they memorized how to un-erode any pile of rubble back into a statue. Now hand them a completely random pile of rubble (pure noise) and whisper a description ("a golden retriever wearing sunglasses"). They chip away, step by step, undoing "erosion" guided by your description, until a coherent image appears.
Step 0 (pure random noise): ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ (static, no image) Step 10 (rough shapes emerge): ▓▓░░▓▓░░░░▓▓░░▓▓░░▓▓ (blurry blob) Step 30 (more defined): ░░▒▒▓▓░░▒▒▓▓░░▒▒░░▒▒ (dog-ish shape) Step 50 (final, denoised): 🐕‍🦺 (a golden retriever wearing sunglasses) Each step: "given this noisy image + the text prompt, predict a slightly less noisy version." Repeat ~20-50 times.

Training a diffusion model works in reverse: take real images, progressively add random noise to them until they're pure static, and train a model to predict "what noise was just added, so I can remove it." Do that at scale across millions of image-caption pairs, and the model learns to "un-noise" its way to any image matching a text description.

3. Audio and video — same diffusion idea, different data

ModalityExamplesCore idea
Text-to-speech (TTS)ElevenLabs, OpenAI TTSGenerate audio waveforms — some use diffusion, others use specialized sequence models
Speech-to-text (ASR)WhisperThe reverse direction — audio in, tokens out (closer to a transformer, not generative in the "creation" sense)
Text-to-videoSora, VeoDiffusion extended across both space (the image) and time (the sequence of frames) — much more compute-intensive

4. Multimodal models — one model, several input/output types

Claude itself is multimodal: it can read images (screenshots, diagrams, photos) as input, even though it only generates text as output. This is different from an image generator — Claude isn't drawing pictures, it's understanding ones you show it, using the same transformer/attention mechanism from Chapter 0a, just with images converted into tokens the same way text is.

Image input → chopped into patches → each patch becomes a "token" │ ▼ fed into the SAME transformer as text tokens │ ▼ text output ("I see a golden retriever...")

This is exactly what powers Chapter 7 (Computer Use) — when Claude looks at a screenshot and decides where to click, it's using this image-understanding path, not a separate "vision AI." One model, multiple input types, single reasoning process.

Terminology check: "Claude can see images" (multimodal understanding) is a completely different capability from "generate me an image" (image generation, like DALL-E). Claude does the former, not the latter — if you want Claude to produce images, you'd have it call out to an image-generation API as a tool (Chapter 11: Tool Use), not generate pixels itself.

5. Where this fits in your curriculum

  • You will build with text models (Claude) for the vast majority of this course — Parts 1–5 are all about that.
  • You may call image/audio APIs as tools from an agent (e.g., "generate a thumbnail" → calls an image-gen API) — that's Chapter 11 territory, not a new modality skill you need to learn from scratch.
  • Multimodal input (showing Claude images/screenshots) is something you already use in Chapter 7 — now you know the mechanism behind it.

Key takeaways

  • Image/video generators mostly use diffusion — starting from noise and iteratively removing it, guided by a text prompt — a fundamentally different mechanism from token-by-token text generation.
  • Diffusion models are trained by learning to reverse a noise-adding process applied to real images.
  • Audio/video generation extends similar ideas across sound waves or sequences of frames, at much higher compute cost.
  • Multimodal (Claude reading images) ≠ image generation (DALL-E producing images) — different capabilities, easy to conflate.
  • As an AI engineer, you'll mostly consume other modalities via API calls/tools rather than build them yourself.
